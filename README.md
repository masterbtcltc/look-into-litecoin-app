# Look Into Litecoin App

A mobile-friendly Litecoin price clock, LTC/BTC ratio tracker, and watch-only portfolio web app from Look Into Litecoin.

## Open the App

Visit:

https://app.lookintolitecoin.com

## Features

* Live Litecoin and Bitcoin prices
* Current LTC/BTC price ratio
* Mobile-friendly price clock
* Watch-only Litecoin portfolio tracker
* Support for multiple public Litecoin addresses
* Locally saved portfolio names, address labels, and public addresses
* Home-screen access on supported iPhone and Android devices
* Responsive design for mobile and desktop screens

## Watch-Only Portfolio

The portfolio feature is watch-only. It displays balances associated with public Litecoin addresses.

This app:

* Does not request or store private keys
* Does not request recovery phrases
* Cannot send or transfer Litecoin
* Does not take custody of cryptocurrency

Never enter a private key or recovery phrase into this app or any website.

Public Litecoin addresses entered into the app are saved in the browser’s local storage on the user’s device. Public addresses and pricing requests may be sent to third-party data providers to retrieve balances and market information.

## Add to iPhone Home Screen

1. Open the app in Safari.
2. Tap the **Share** button.
3. Select **Add to Home Screen**.
4. Confirm the app name and tap **Add**.

## Add to Android Home Screen

1. Open the app in Chrome.
2. Tap the browser menu.
3. Select **Add to Home screen** or **Install app**.
4. Confirm the installation.
